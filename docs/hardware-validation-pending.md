# 待硬件验证清单

下列项目当前均未经过实机验证，不得在设计、报告或测试记录中伪装成已经验证。

| 待验证项目 | 当前证据边界 | 后续建议 |
|---|---|---|
| PD7复位期间电平 | 原理图未配置外部下拉，复位至GPIO初始化之间存在高阻窗口 | 用示波器验证上电波形；评估增加约10 kΩ下拉 |
| RC接收机实际失联输出 | 尚无当前接收机的实测脉宽/保持策略 | 分别测试断发射机、断接收机信号和低电压场景 |
| MSSD抱闸输出配置 | 尚未从实机参数和接线确认 | 核对驱动器参数、输出极性、继电器/制动器接线 |
| MSSD通信超时寄存器 | 尚未确认当前驱动器是否配置及其单位 | 对照准确型号手册读取配置并做断线验证 |
| 左右轮方向 | 尚未实测电机安装方向、编码器符号和正转定义 | 架空轮、零速起步、逐轮验证并记录符号 |
| 急停距离 | 无车辆质量、速度、坡度和制动实测 | 在受控场地分速度和坡度测量最坏停车距离 |
| 零速抱闸时序 | 无速度反馈阈值、机械延迟和电气波形实测 | 同步记录速度反馈、速度命令和制动输出，确定超时与阈值 |

任何一项未完成时，不得把当前固件用于直接连接电机的车辆试车。

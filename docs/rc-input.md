# RC输入模块离线设计

本页保留接收器实测前的设计记录。正式轮式使用已实测的通道映射，独立档由 CH1/2/6/7 决定控制输入有效性。操作及无线关机时的接收机输出见[正式固件烧录与使用说明](../../../wheel-firmware/正式固件烧录与使用说明.md)。

## 证据边界

本模块仅完成离线实现和编译验证，尚未连接遥控接收机、开发板或车辆。以下旧工程信息只用于确定兼容边界，不复制旧状态机或电机控制逻辑。

旧工程源码能够证明：

- `Drivers/BSP/RC/rc.c:4-7,127-150`：CH1/CH2/CH5/CH6分别使用PC6/PC7/PC8/PC9和TIM8_CH1~CH4，CH7使用PA6和TIM3_CH1；定时器为1 MHz、ARR=65535。
- `Drivers/BSP/RC/rc.h:14-32`：旧接收范围为500~2500 us，三档窗口为900~1100、1400~1600和1900~2100 us，相同档位需连续3个样本；旧CH5另有200 ms时间门限。
- `Drivers/BSP/RC/rc.c:156-220`：上升沿记录计数，随后切换到下降沿；下降沿计算高电平并切回上升沿，显式处理16位回绕。
- `Drivers/BSP/RC/rc.c:434-470`：CH1中心1500 us且方向反转，CH2中心1500 us且方向不反转；旧连续值按500 us满量程换算并钳位。
- `Drivers/BSP/RC/rc.c:198-216,380-426`：档位采用连续3样本稳定值，但CH5启动混用了已稳定中档和单帧高档，停止路径随后被禁用。
- `Drivers/BSP/RC/rc.c:277-359`及`User/main.c:265-290`：旧工程在INSPECTING中忽略RC并停止输入捕获，使CH7不能持续作为独立急停输入。
- `Drivers/BSP/RC/rc.c:298-335`：旧急停解除没有独立稳定确认，CH6中间/非法档可能回退REMOTE。
- `Drivers/BSP/RC/rc.c:19-27,195-216,453-470`：ISR与主循环共享结构没有一致性快照；未见逐通道新鲜度或失联超时，旧脉宽可被继续钳位成非零摇杆量。
- `User/main.c:366-398`：旧REMOTE路径直接调用电机和刹车函数；该路径未复制到新工程。

## 分层与数据流

`Bsp/rc_capture`依赖HAL，只负责TIM3/TIM8捕获。每个通道初始捕获上升沿，捕获后切换下降沿；下降沿通过16位无符号减法计算脉宽并切回上升沿。ISR只更新时间戳、最新值和固定容量样本队列，不执行消抖、状态切换、打印、延时或串口操作。

主循环通过 `rc_capture_take_sample()` 逐项取出样本并交给 `rc_input_process_sample()`。受短临界区保护的 `rc_capture_read_snapshot()` 提供每通道最新值和丢样计数。组合层检查丢样并进入安全处理。

`Services/rc_input`是纯C逻辑，不包含HAL头文件。它验证脉宽、输出CH1/CH2的-1000~1000整数、生成CH5单次启动边沿、稳定CH6模式、快速触发/稳定解除CH7急停，并用无符号毫秒差检查所有五个关键通道的新鲜度。它只返回抽象事件，不调用状态机或硬件。

## 离线参数

| 参数 | 当前值 | 依据与限制 |
|---|---:|---|
| 捕获计数频率 | 1 MHz | 新CubeMX配置PSC=71，TIM3/TIM8输入时钟72 MHz |
| 16位计数周期 | 65536 us | ARR=65535；用`uint16_t`减法处理一次回绕 |
| 物理脉宽范围 | 500~2500 us（含边界） | 沿用旧工程噪声过滤外边界，待接收机实测 |
| 摇杆中心 | 1500 us | 旧源码参考 |
| 摇杆死区 | ±50 us（含边界） | 新固件离线保守设计值，待实测噪声后调整 |
| 摇杆输出 | -1000~1000整数 | CH1反向、CH2正向；不生成轮速 |
| 低档窗口 | 900~1100 us | 旧源码参考 |
| 中档窗口 | 1400~1600 us | 旧源码参考；CH6/CH7不把中档解释为合法模式 |
| 高档窗口 | 1900~2100 us | 旧源码参考 |
| CH5触发/重新布防 | 连续3个高档/连续3个非高档样本 | 新安全规则；保持高档不重复触发 |
| CH6模式确认 | 连续3个同档样本 | 低档REMOTE，高档STANDBY；中间/非法值不切换 |
| CH7急停触发 | 1个合法高档样本 | 优先快速触发 |
| CH7急停解除 | 连续3个合法低档样本 | 非法样本打断计数，失联不产生解除事件 |
| CH1/CH2中位确认 | 3组完整的双通道中位样本 | 任一通道离开死区或失效即重新计数 |
| 五通道新鲜度超时 | 100 ms | 新固件离线保守设计值，按50 Hz约丢5帧估算；启动监测也有同等宽限期，待实测 |

所有时间差均使用`(uint32_t)(now_ms - previous_ms)`，允许32位毫秒计数正常回绕。首次轮询或首次合法样本启动100 ms监测宽限期，避免系统在首帧到达前立即误报；其后任何关键通道超时仅产生一次`RC_INPUT_EVENT_SIGNAL_LOST`边沿并清零摇杆输出。信号恢复只重建输入有效性，不产生解除FAULT的状态机事件。

## 当前集成边界

- 正式入口经 `chassis_app_start()` 启动 TIM3/TIM8 捕获，前台 `chassis_app_poll()` 将 RC 事件交给状态机。
- 上述路径已进入 ARM 映像；当前接收器的接线、实际 PWM、发射机关闭后的输出以及中断时序需板级观测。
- 模块不访问GPIO输出、UART、DMA、LED、蜂鸣器、电机、MSSD或刹车。
- 模块不生成轮速、Modbus帧、松闸请求或非零速度命令。
